# Редактирование v7

1. Субтитры: нажмите на название нужной фразы в таймлайне. Справа в Inspector найдите Text и исправьте текст. Границы клипа задают время показа.
2. Музыка: прокрутите список дорожек вниз, выберите «Музыка • Sidequest». В Inspector → Controls нажмите значение Volume. Сейчас 0.10 (−20 дБ). Для более тихой музыки — 0.05; для более громкой — 0.18 или 0.32. Change source заменяет файл.
3. Голос имеет собственный клип «Голос • voice.wav». Его громкость меняется отдельно.
4. Пустой музыкальной дорожки нет. Добавляйте реальные файлы штатным способом Studio, как уже добавлена Sidequest.
5. Направляющие не экспортируются. Проверка типов пройдена, в Studio проверены поле Text и регулятор Volume.

Субтитры пока занимают отдельные строки Studio. Интерфейс с несколькими клипами на одной дорожке, как в Premiere, требует отдельного редактора.
