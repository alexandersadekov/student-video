# Интернет-исследование для визуального монтажа

Remotion и локальный Python-импорт не исследуют интернет. Они готовят видео, транскрипт и редактируемую композицию. Исследование выполняет Codex/ИИ, которому доступен веб-поиск.

После импорта откройте папку `public/projects/Video-...` и дайте Codex команду:

> Исследуй интернет по RESEARCH_REQUEST.md. Используй актуальные первичные официальные источники. Для каждого факта, процесса, логотипа и ассета заполни SOURCES.md с прямой ссылкой и датой проверки. Затем предложи scenes.json для Style1 и Style2. Не используй материалы без понятного разрешения и не выдумывай данные.

Файл `RESEARCH_REQUEST.md` создаётся автоматически для каждого нового импорта. Само наличие файла не запускает сеть: запрос должен выполняться в задаче Codex с доступным web search. Официальная документация OpenAI описывает web search как отдельный инструмент; в API его можно включить и сделать вызов инструмента обязательным через `tool_choice: required`. Это уже отдельная API-автоматизация с ключом и оплатой вызовов, в текущие CMD-скрипты она не встроена.

Порядок источников: официальный бренд-кит/документация/оригинальное исследование → государственный или отраслевой первичный источник → качественный вторичный источник только при отсутствии первичного. Для быстро меняющейся информации фиксировать дату проверки.

По результатам исследования агент должен создать:

- `SOURCES.md` — утверждение, таймкод, визуал, URL, дата и ограничения;
- `scenes.json` — итоговые таймкоды и локальные пути к разрешённым материалам;
- список материалов, которые нужно запросить у автора;
- отметку, где лучше оставить человека и приближение вместо слабой иллюстрации.
