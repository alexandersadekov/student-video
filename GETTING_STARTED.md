# Свой проект: от запуска до первого ролика

Это учебная основа, а не библиотека чужих монтажей. Демосцены показывают приёмы; агент должен создавать сценарий по вашей речи, а не копировать их в каждый ролик.

1. Сделайте Fork репозитория в свой GitHub-аккаунт и клонируйте его. Авторизация GitHub CLI: `gh auth login`. Она нужна для отправки изменений, не для локального монтажа. Используйте только собственный аккаунт; токены не сохраняйте в проекте.
2. Запустите SETUP.cmd. Он устанавливает зависимости; нужны Node.js, Python и FFmpeg. Затем START-STUDIO.cmd. Проверьте Motion-Examples и демо стилей.
3. Настройте editing-profile.json: шрифт, субтитры, нарезка, кадрирование и стиль. Эти параметры применяются к следующему импорту.
4. Перетащите своё видео на IMPORT-VIDEO.cmd. Это черновой технический проход; он не выбирает лучший дубль и не создаёт смысловые анимации сам.
5. Откройте проект в своём ИИ-агенте и дайте ему задание ниже. Доступ к ИИ настраивается в самом агенте; GitHub-авторизация его не заменяет.
6. Проверьте ролик, поправьте текст и ключи в Studio, экспортируйте через EXPORT.cmd.

## Задание агенту

> Прочитай AGENTS.md, MONTAGE_RULES.md и motion-direction.json. Импортируй мой файл [путь]. Сначала сравни дубли по смыслу и сохрани выбранные/отклонённые интервалы с причинами; если выбор неоднозначен, спроси. Для каждой фразы составь план: предмет → действие → результат. Выбирай smooth/bounce/morph по смыслу, не копируй демонстрационный сюжет. Запроси недостающие материалы. Используй Inter, проверяй паузы, зависания сцен, яркость и финальную часть мысли. Сохрани редактируемую композицию. Перед выдачей проверь рендер и сообщи, какие проверки действительно выполнены.

## Где менять поведение

- editing-profile.json — исходные настройки импорта.
- scripts/import-video.py — техническая обработка и генерация клипов.
- motion-direction.json и AGENTS.md — планирование агентом.
- src/MotionExamples.tsx — кривые smooth/bounce/morph.
- src/generated — собственные редактируемые монтажи (не публикуются).
- src/local — собственные дополнительные композиции (не публикуются).

Видео, голос, субтитры и результаты импорта сохраняются локально и исключены из Git. Их нужно резервировать отдельно. В общий репозиторий отправляйте код и обезличенные примеры. Перед push: `node scripts/check-template.cjs`, `npm run lint` и тесты из README. Не используйте git add -f для личных файлов.
